# Respect the Process
Steps to follow in coding interviews

## 1. Discuss and ask clarifying questions (3 mins)

## 2. Propose different possible directions and discuss trade-offs (2 mins)
- Do not need to go to the optimal solution directly.
- Can always start by considering the brute-force solution.

## 3. Pseudo-coding (optional)

## 4. Speak out the thought process and ask for feedback while implementing (15 mins)

## 5. Dry run and edge cases (3 mins)

## 6. Discuss time and space complexity (2 mins)

## 7. Time management
